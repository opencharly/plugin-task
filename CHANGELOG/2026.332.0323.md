# 2026.332.0323 — feat(git-submodules)!: fast-forward pins and fail a behind one

## Summary

`verb:git-submodules` stops asking about tags and starts tracking the branch.

- **`bump` → `ff`**, and it is now a real fast-forward. A move whose target is not a descendant of the checkout's current HEAD is REFUSED by name — path, both commits, direction — and that submodule is left exactly as it was: not switched, not staged, its nested checkouts not reconciled. The same guard applies to both phases, so an edge whose twin is BEHIND the checkout is refused rather than rewound (the producer advances first).
- **`currency` FAILS on `behind`**, and on a `blocked-by` that names a real producer leg. The message leads with the count of pins that are not current, names each one, and names the remedy `charly task ff`. The one reported non-failure is `differs (no checkout to judge ancestry)`, which is genuinely unjudgeable — a light tree must not manufacture a red it cannot prove.
- **The tag relation is deleted**: the per-pin `; tag …` / `; no tag at served` facts, the whole-tree tag tally, and the `design-pintag` pointer. No tag is consulted for a verdict.
- **`stale_after` and the neglect bound are deleted.** Strictness replaces the bound: a pin behind the tip its intent names fails now.

Round 2 (the BLOCK this answers): the refusal path is now driven live through the fresh-built binary, the nested fixture ASSERTS the ancestry its comment claims, and the R12 round spikes every plausible instrument.

### Spike

Real fixture, real git, throwaway dir `/tmp/ff-spike/r12` (`origin.git` `main = A→B`; a clone detached at `A` with a local commit `C`, so `C` is a sibling of `B` — the hazard; and a behind clone at `A`). A=`bddb4fd365202f6292e4d92cba1e51205be23d39`, B=`8b2c585c921026c4fac323ec41c0f0d0568434bb`, C=`2b1ac584bd2bf20d639a4f430fc63f83187cd6f7`.

**A — ancestry guard (`git merge-base --is-ancestor HEAD <target>`): WORKS.**

```
$ git merge-base --is-ancestor HEAD 8b2c585c921026c4fac323ec41c0f0d0568434bb; echo guard-exit=$?   # HEAD=C, diverged
guard-exit=1
$ git rev-parse HEAD
2b1ac584bd2bf20d639a4f430fc63f83187cd6f7          # unchanged: a pure object-store read
$ git merge-base --is-ancestor HEAD 8b2c585c921026c4fac323ec41c0f0d0568434bb; echo guard-exit=$?   # HEAD=A, behind
guard-exit=0
```

**B — `git merge --ff-only <target>`: FAILS as the guard.**

```
$ git merge --ff-only 8b2c585c921026c4fac323ec41c0f0d0568434bb; echo merge-exit=$?   # diverged
fatal: Not possible to fast-forward, aborting.
merge-exit=128
$ git merge --ff-only 8b2c585c921026c4fac323ec41c0f0d0568434bb; echo merge-exit=$?   # behind
Updating bddb4fd..8b2c585
Fast-forward
 create mode 100644 b
merge-exit=0
$ test -f .git/post-merge-fired && echo post-merge-hook=FIRED || echo post-merge-hook=not-run
post-merge-hook=FIRED
```

It refuses the right case, but on the allowed one it **IS the move** (working tree and index updated, the `post-merge` hook run), so it cannot be a precondition ahead of the nested judgement/switch/stage/reconcile, and its refusal names no path or direction.

**C — rely on `switch --detach` failing on a dirty tree: FAILS.**

```
$ git status --porcelain
(clean — the work is a commit, not a dirty file)
$ git switch --detach 8b2c585c921026c4fac323ec41c0f0d0568434bb; echo switch-exit=$?
switch-exit=0
$ git for-each-ref --contains 2b1ac584bd2bf20d639a4f430fc63f83187cd6f7 --format='%(refname)'
(empty — C is in ZERO refs; the object survives only in the reflog)
```

**D — reachability guard (`git for-each-ref --contains HEAD`, the `judgeNestedCheckout` shape): FAILS for THIS checkout.**

```
$ git for-each-ref --contains HEAD --format="%(refname)"
(empty => would REFUSE)
$ git branch keep
$ git for-each-ref --contains HEAD --format="%(refname)"
refs/heads/keep
(non-empty => would ALLOW — and `switch --detach` then moves a branch-backed checkout off its head)
```

It is the right instrument where the move is `git submodule update` (unchosen; the question is "does this commit stay reachable?"), not where `ff` CHOOSES the target and "only advances" is the contract.

**E — a reflog check: FAILS.**

```
$ git reflog show HEAD --format='%h %gs'
2b1ac58 commit: C (local work)
bddb4fd checkout: moving from main to bddb4fd…
$ git switch --detach 8b2c585c921026c4fac323ec41c0f0d0568434bb
$ git reflog show HEAD --format='%h %gs'
8b2c585 checkout: moving from 2b1ac58… to 8b2c585…      # written BY the destructive act
```

`C` is in the reflog before AND after; the only entry that reports the loss is written by the move itself. An observation after the fact cannot be a precondition.

**Winner: A** — refuses exactly the unsafe move, allows exactly the safe one, side-effect-free, and runs before every write. The diff implements A.
